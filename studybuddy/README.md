# StudyBuddy

A friendly AI study partner for people who prefer not to study alone, or in a crowd.
Built for the Build, Ship, Shape: Amazon Developer Hackathon (Alexa+ track, simulated experience).

## Run it
1. Install Python 3.10+
2. `python -m venv venv`
3. Activate: Windows `venv\Scripts\activate` | Mac/Linux `source venv/bin/activate`
4. `pip install -r requirements.txt`
5. `python app.py`
6. Open http://127.0.0.1:5000
